# Test CrewAI Snippets

Este projeto é para testar os snippets da extensão CrewAI.

## Como testar

1. Instale a extensão crewai-snippets-0.0.4.vsix no VS Code
2. Abra o arquivo test_snippets.py
3. Digite os prefixos dos snippets para testá-los:
   - `crew-agent`
   - `crew-task`
   - `crew-crew`
   - `crew-simple-tool`
   - etc.
